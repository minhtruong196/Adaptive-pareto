DUAL-STATOR VERNIER MOTOR — GEOMETRIC CONSTRAINTS AND DESIGN VARIABLES
English translation of Contrain.docx for Codex

PURPOSE AND MODEL CONTEXT

This document describes constraints and candidate design variables for my dual-stator Vernier motor model in Ansys. Because the model has two stators, it has many variables. I built the parameterization myself, so it is less systematic than Motor-CAD's ratio-based parameterization.

Please inspect and discuss any unclear dependencies before implementing them. Do not silently assume that all variables are independent.

1. CONSTRAINTS AND COUPLED VARIABLES

1) Dshaft / inner stator yoke coupling

   When Dshaft increases by 2 units, sta_yoke_thickin must decrease by 1 unit. Other model variables depend on Dshaft, and sta_yoke_thickin needs to compensate for the geometric change. In physical terms, a larger shaft diameter requires a thinner inner-stator yoke in this model.

   When changing Dshaft, update sta_yoke_thickin automatically and enforce:

       sta_yoke_thickin > 0

   The inner-stator yoke thickness must remain strictly positive.

2) Positive inner winding-space constraint

       (Dsin/2 - slot_d_axin - slot_tipin) - (Dshaft/2 + sta_yoke_thickin) > 1 mm

   Updated by the user on 2026-11-14: inner winding space must also be strictly greater than 1 mm. Current constraint set version 4 requires both inner and outer winding spaces > 1 mm. Python inner_winding_mm and outer_winding_mm represent the surplus above 1 mm; reject margins <= 0.
   Confirmed by the user on 2026-11-13: 'sta_yoke' in the original note means 'sta_yoke_thickin', the inner-stator yoke thickness. It is not a separate variable.

3) Positive permanent-magnet thickness constraint

       (Dsout - 4*g - Dsin)/2 - (pm_bridin + pm_bridout) > 0

   This constraint is intended to keep the magnet thickness strictly positive.

4) Inner axial slot depth / slot-tip coupling

   When slot_d_axin increases by 1 unit, slot_tipin must automatically decrease by 1 unit, similar to Constraint 1. Enforce:

       slot_tipin > 0
       slot_d_axin > 0

5) Inner slot-angle constraint

       slot_ang_axin < 360deg/2/Ns

5a) Inner winding / split-tooth clearance (added by the user after video review)

       Dsin/2 - (Dsin/2 - slot_d_axin - slot_tipin)/cos(slot_ang_axin) > slot_d_axin

   This prevents the inner winding from intruding into the split tooth. slot_ang_axin is in degrees; Python must convert it to radians before calling math.cos. Enforce the strict positive margin Dsin/2 - (Dsin/2 - slot_d_axin - slot_tipin)/cos(slot_ang_axin) - slot_d_axin. This is constraint set version 2; earlier geometry validation results did not include this condition. Keep the agreed variable bounds unchanged.

6) Positive outer winding-space constraint

       (Dsout_out/2 - sta_yoke_thickout) - (Dsout/2 + slot_d_axout + slot_tipout) > 1 mm

   Updated by the user on 2026-11-14 after point 8 produced null outer winding bodies: require strictly more than 1 mm, not merely positive space. Constraint set version 3. The Python outer_winding_mm margin subtracts this 1 mm threshold; reject margins <= 0.

7) Outer slot-angle constraint

       slot_ang_axout < 360deg/Ns

   Note: This differs from the inner slot-angle expression because the inner and outer geometry were parameterized differently.

8) Outer axial slot depth / slot-tip coupling

   When slot_d_axout increases by 1 unit, slot_tipout must automatically decrease by 1 unit, similar to Constraint 1. Enforce:

       slot_tipout > 0
       slot_d_axout > 0

9) Permanent-magnet overlap constraint

       arctan(d_pm/(Dsin + 2*g)) < 360deg/2/p

   This constraint is intended to prevent magnets from becoming so wide that adjacent magnets overlap.

10) Current density

       J = 5.5

   The current-density calculation is documented in readme.md. The RMS current, I_rms, must be adjusted automatically according to that calculation.

11) Fixed parameters

       kfill = 0.3

   Updated by the user on 2026-11-15: use kfill = 0.3 for the new 800-call campaign. Override the saved template value before each evaluation and recalculate I_rms from actual areas with J <= 5.5 A/mm2. Keep earlier kfill=0.4 results separate. Do not change kfill within a campaign. All parameters not explicitly identified for optimization should remain fixed.
